# Aurora Live App

A React Native (Expo) live-streaming frontend prototype with creator discovery, live calls, gifts, coin recharge, chats, profiles, settings, and Lenis-powered smooth scrolling.

## Run locally

```bash
npm install
npm start
```

Then open the project in Expo Go, or run `npm run android` / `npm run ios` for a native build.

## Architecture

The Aurora UI is a self-contained web bundle rendered inside a `react-native-webview`, so the interface is identical to the previous Next.js version.

- `App.tsx` — React Native shell: the WebView, safe-area handling, and a bridge that mirrors the page's `data-theme` onto the native status bar
- `web/` — the UI sources (`aurora.css`, `aurora-runtime.js`, `app.css`, plus vendored Lenis)
- `assets/aurora.html` — generated single-file bundle of everything in `web/`; also openable directly in a browser
- `assets/aurora-bundle.js` — generated, the same bundle as a JS module, which is what the WebView is handed

### Changing the UI

Edit the sources in `web/`, then regenerate the bundle:

```bash
npm run build:web
```

Both files under `assets/` are generated by `scripts/build-web.mjs` — do not edit them by hand.

## Notes

This is a frontend prototype. Authentication, payments, WebRTC, and realtime services are represented by local demo interactions.
