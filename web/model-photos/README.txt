Licensed stock photos of models for the welcome screen and the design preview.

Files: model-1 to model-6, as .webp, .jpg or .png (for example model-1.jpg).
  model-1..3  welcome screen cards in the app and the preview (all three are needed)
  model-1..6  the preview's sample hosts: Ananya, Meher, Ishita, Noor, Kavya, and Tara/Sara
Size: portrait, at least 720 x 960, under 150 KB each (WebP keeps them small).
Run `npm run build:web` after adding or changing a file. A missing file falls back to
web/onboarding-media/.

Only use photos bought from a stock library (Shutterstock, Adobe Stock, Getty/iStock) whose
licence allows use in a social or dating app's own screens and advertising. Keep each licence or
receipt next to the photo, e.g. model-1.licence.pdf. With model photos in place, the app shows
"Photos posed by models", which these licences usually require. Never use free-stock or
social-media photos of people here.
